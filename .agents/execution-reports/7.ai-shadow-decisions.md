## Executive Summary

Built a flag-gated (`AI_SHADOW_ENABLED=False` default) AI decision module that runs a
two-call daily-trend→next-move mini-orchestrator ALONGSIDE the hypothesis engine at the same
triggers, logs paired records (hypothesis said X, AI said Y, price did Z), and changes NOTHING
about trades or P&L. Trades are byte-identical **by construction** (shadow never mutates strategy
state); the flag-OFF 1s A/B is byte-identical on both a trend and a chop day, and the flag-ON run
keeps trades + the non-AI event subsequence unchanged. All four mandated validations pass; the
single real-API day cost ≈$0.81 (< $2 ceiling). All changes are UNSTAGED; nothing committed.

## Divergences from Plan

### Divergence #1: Latency constant 79 s, not the plan's seed of 75 s

**Classification:** ✅ GOOD
**Planned:** Config seed `SHADOW_DECISION_LATENCY_SEC = 75`.
**Actual:** Set to `79.0`.
**Reason:** Phase-0 T0.2 mandates the *measured rounded mean*; the 5 real `decision.json` cycles
mean to 78.7 → 79.
**Root Cause:** The `75` in the config block was an explicit pre-measurement estimate; the plan's
own instruction supersedes it once measured.
**Impact:** Neutral/positive — the emulated arrival is grounded in real data.
**Justified:** Yes.

### Divergence #2: Phase-3 flag-OFF/ON full-backtest cases reframed as pipeline-wiring tests

**Classification:** ⚠️ ENVIRONMENTAL
**Planned:** `tests/test_shadow_integration.py` runs a short full 1m regression day and asserts
events+trades byte-identity (flag OFF) and trades-identity (flag ON) in-process.
**Actual:** Those in-process full-backtest cases were reframed as pipeline-wiring tests
(flag-OFF leaves `emit` untouched; shadow mirrors `new-hypothesis` without mutating the event;
checkpoints fire once each / only-crossed; short-day finalize is clean).
**Reason:** pytest's autouse `ACT_GLOBAL_DIR` isolation leaves `run_backtest_v2` with no futures
data in-process, so a real backtest can't run under the unit harness.
**Root Cause:** Test-environment fixture isolation, not a code gap.
**Impact:** Neutral — the real flag-OFF/ON byte-identity is proven at scale by the Phase-6
regression A/B (2026-05-19 trend + 2026-05-18 chop) instead, which is the stronger check.
**Justified:** Yes.

### Divergence #3: `facts_to_validator_dict` delegates to calibration `parse_facts`, omits `tier`

**Classification:** ✅ GOOD
**Planned:** Build the validator dict `{now_price, levels{name:{price,swept,depleted,side,tier}},
checkpoint}` directly from the bundle.
**Actual:** `facts_to_validator_dict` delegates to `calibration.parse_facts(render_facts_text(bundle))`
("one source, two views") and omits the `tier` key the semantic validator never reads.
**Reason:** Guarantees the online JSON view is identical to what the calibration bench yields for the
same facts (closes HOLE H4) rather than maintaining a parallel derivation that could drift.
**Root Cause:** Plan gap — the plan specified the dict shape but the delegation is the safer way to
hit the "same as `parse_facts`" acceptance test.
**Impact:** Positive — single source of truth; validator-dict parity test passes on committed cuts.
**Justified:** Yes.

- `facts_to_validator_dict` `levels`/`now_price`/`checkpoint` equal `parse_facts(render(bundle))` on committed cuts.

- Bars after `now` never enter the bundle (no-lookahead precondition).
- `decide()` on a cut's in-memory facts is byte-equal to `run_cut()` on the same cut (stub backend).
- A stub backend returning schema-valid-but-protocol-violating JSON twice yields `failsafe` (NEUTRAL/LOW).
- Backend auto-select prefers OpenRouter, falls back to Anthropic, and errors clearly with no keys.
- A snapshot from live frames byte-equals `render_facts_text` from the equivalent parquet slices.
- A snapshot at checkpoint C contains no bar `> C` even when `now > C`.
- Identical frames hash identically; a one-bar change changes the `content_hash` (drift detector).
- The no-lookahead guard raises on a bar at `trigger_ts + 1s` and passes a bar exactly at `trigger_ts`.
- Replay cache: miss-then-hit returns cached with zero backend calls; corrupt entry is treated as a miss; concurrent writes stay atomic.
- Audit records round-trip and reload against the schema; the events-native `new-hypothesis`/`daily-trend` shapes carry every real key plus `source:"ai-shadow"`; snapshots store inline or as file+hash.
- `on_checkpoint` sets the standing daily-trend and a later `on_hypothesis_trigger` consumes it; a trigger before any checkpoint uses a neutral default.
- A poisoned snapshot yields an `error="lookahead"` record with no API call and clean engine return (finally-cleanup path); a forced failsafe yields `verdict="failsafe"`.
- The churn guard suppresses a second trigger with no new event (no new API call).
- Annotation: target-reached-first, flip-fired-first, neither-within-horizon, and truncated (no post-arrival bars) against synthetic price paths.
- Consistency check: matching offline/online paths → zero drift; an injected week-anchor difference is flagged with the diffing section named.
- Comparison harness builds agree/disagree counts and per-day cost/latency and renders a text table.
- Live wrapper: job computed off-thread (loop returns immediately), staleness flags a discarded record, worker survives an exception, shutdown drains/joins the queue.
- Integration: flag OFF leaves `emit` untouched; the shadow mirrors `new-hypothesis` without mutating the event; the four ET checkpoints fire once each (only crossed ones on a mid-start day); a short day finalizes cleanly.

## Challenges & Resolutions

**Challenge 1 — `derive_facts` was a print-only script (HOLE H4).**
- **Issue:** All S0–S7 maths inline in `main()`; the text→dict reverse (`parse_facts`) lived in
  `calibration/`, not `agent/`.
- **Root Cause:** POC code was written to print, never to be imported.
- **Resolution:** Extracted pure `compute_facts`/`render_facts_text`, and made
  `facts_to_validator_dict` delegate to `parse_facts(render(...))` so the online JSON view can't
  drift from the calibration bench.
- **Prevention:** When a POC script's output will be consumed programmatically, extract the pure
  core up front.

**Challenge 2 — `compute_facts` ran ~25 s per call, tripping a per-test timeout.**
- **Issue:** A per-test timeout flake in the shadow suite; the shadow runtime was also slow.
- **Root Cause:** A row-wise trade-date map inside `session_frame`.
- **Resolution:** Vectorised the trade-date map (code-review fix) → 25 s to 0.68 s, byte-identical
  output (golden test still green).
- **Prevention:** Profile any pure function placed on a per-trigger hot path before wiring it in.

**Challenge 3 — In-process full-backtest integration tests can't get futures data.**
- **Issue:** The planned flag-OFF/ON full-backtest cases couldn't run under the unit harness.
- **Root Cause:** Autouse `ACT_GLOBAL_DIR` isolation strips `run_backtest_v2`'s data root.
- **Resolution:** Reframed those cases as pipeline-wiring tests; moved the real byte-identity proof
  to the Phase-6 out-of-process regression A/B.
- **Prevention:** Reserve full-backtest identity checks for the regression harness, not pytest.
