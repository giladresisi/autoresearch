## Challenges & Resolutions

**Challenge 1:** Routing a code-derived magnitude lookup from where the `FactsBundle` lives
(`bench/facts.build_facts`) down to `score_thesis_evidence` without breaking existing call sites.
- **Issue:** `_derive_thesis_arithmetic` was passed bare as `derive_block`; the scorer had a fixed
  single-arg signature.
- **Root Cause:** The decision-arithmetic path is a closure chain (`decide_thesis → _run_call →
  derive_block(parsed)`); adding an input meant threading through three layers.
- **Resolution:** Made `magnitude` / `evidence_magnitude` optional (default `None`) at every layer and
  passed the lookup via a `lambda d: _derive_thesis_arithmetic(d, magnitude=...)` closure. `None` /
  missing key → ×1.0, keeping `test_contracts.py` / `test_run_agent.py` byte-identical.
- **Time Lost:** Minimal — the plan pre-identified this as the one non-trivial wire.
- **Prevention:** N/A — handled by the plan's interface contract.

**Challenge 2:** Preserving S0–S7 byte-stability while adding seven new bundle fields and three S9
sub-blocks.
- **Issue:** Any accidental `L(...)` call or validator-dict addition would break the shadow-engine
  facts-identity hash.
- **Resolution:** Every new value is an additive dataclass field rendered only in `render_evidence_text`
  (S9) / menus (S8), never appended to `bundle.lines` or the validator dict. Verified by the unchanged
  S0–S7 hash before/after.
