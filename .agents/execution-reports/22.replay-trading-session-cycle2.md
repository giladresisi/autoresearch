## What was tested

**`CallOutcome` capture (Task 1, gate 8)**

- A backend returning a bare dict still works — the cycle-1 contract is preserved.
- Latency, tokens and cost are captured when the backend supplies them.
- `call_meta` is persisted into `thesis_state.json` and survives a reload, so a mid-session restart
  does not lose the standing thesis's provenance.
- A failing backend records no meta and leaves no thesis behind.
- The `thesis_via_decide_thesis` adapter widens to `(thesis, meta)` instead of dropping the wrapper.
- **Divergence guard:** the REAL `run_agent.CallOutcome` shape yields latency and usage through the
  alias table, so a field rename cannot silently empty the meta.

**Arrival gate (Task 4)**

- Zero latency is visible immediately, preserving cycle-1 behaviour.
- The thesis is invisible before the latency has elapsed, visible exactly at the boundary, and stays
  visible after it.
- Calling `standing_thesis` without `now` bypasses the gate (back-compat for live callers).
- `armed_at` records the bar time of the arm and survives a reload, so the gate holds across a restart.
- A dark day stays dark regardless of the gate.
- The graft passes bar time into `standing_thesis` — without this the gate is inert where it matters.

**Thesis cache (Task 2, gate 4)**

- Identical inputs produce an identical key; the key is short and hex.
- Changing any keyed input (facts, KB, model, task prompt, schema) changes the key; schema dict
  ordering does not, so serialisation order cannot manufacture phantom misses.
- `put`/`get` round-trips the thesis; a missing key is a miss, not an error.
- The record carries `meta` and `boundary` for debugging.
- A corrupt entry reads as a miss rather than raising, so the run recovers by re-calling.
- `put` is atomic and leaves no partial file; `clear` removes every entry and reports the count.
- The cache root defaults under `<global>`, not the worktree, and an env override wins.

**Cached backend (Task 3, gates 3 and 5)**

- A miss calls the inner backend and records the result; the second identical call is a hit that does
  not touch the inner backend and says `cached` in its meta.
- Changing the facts text, the KB (a doc edit is a strategy change) or the model forces a miss; an
  unkeyed field such as `evidence_magnitude` does not.
- `allow_calls=False` raises on a miss rather than calling, and still serves a hit.
- A `None` thesis is not recorded — a failed call must not poison the cache with a permanent dark day.
- **A `failsafe` verdict is not recorded**, while a `clean` verdict is.
- A refusal is *counted* as well as raised, because `Analyzer._call` swallows every exception.
- The `boundary_hint` reaches the record when facts carry no boundary, facts still win when they do,
  and two dates with identical facts do not collide.
- A hit replays the recorded latency and usage all the way into `Analyzer.call_meta()`.

**Replay window and history extension (Task 5)**

- The slice starts at the window start and ends at the window end (exclusive).
- **The history is extended to the window start** — the critical assertion; without it the entire
  overnight session vanishes from both the Analyzer's facts and the Executor's store.
- The extended history covers the overnight session with no gap, meets the slice without overlap, and
  is 1m resolution.
- A window start at the session open leaves history untouched; an empty window returns empty bars
  without raising.
- **Regression (HIGH review finding):** the bridge does not duplicate the history's final minute,
  preserves that bar untouched, and still resumes at `hist_end + 1m` so the fix opens no gap. These
  three use the real parquet's geometry, which the plan's own fixture could not reproduce.
- The OHLC of the resampled history aggregates correctly.

**Runner and CLI (Tasks 6–7, gate 1)**

- `run_backtest_v2` accepts `trader_factory` and `replay_window`, constructs the pipeline with
  `trader=`, and applies the window through `replay_slice`.
- With both new parameters unset the legacy path is byte-identical.
- A `replay_window` outside 1s mode is refused, not silently ignored.
- The window is 09:20→11:00 ET and the end is 11:00, not the DOL.
- The default arrival latency is the measured p50.
- The replay Analyzer runs inline (not threaded), carries the arrival gate, and uses the cached backend.
- `allow_calls=False` is the default for `run_replay`, so a replay cannot accidentally spend money or

- `run_replay` never writes a regression baseline — asserted by an AST walk that excludes docstrings

- The CLI exposes the dates, seed and latency flags.

## Divergences from Plan

### Divergence #1: The plan's coverage command reads the wrong directory

**Classification:** ✅ GOOD (plan gap corrected)
**Planned:** Task 8 Step 1 checks 1s coverage via `paths.general_main_dir() / 'MNQ_1s.parquet'`.
**Actual:** Coverage was checked through `_main_dir_for_date(date)`, the resolver `run_backtest_v2`
actually uses — contract rollover routes 2026-08-12 to `<global>/general/main/2026-09/`.
**Reason:** The plan's command reports 0 bars for a date that has full coverage.
**Root Cause:** Plan gap — the contract-rollover indirection was not accounted for.
**Impact:** Positive. Following the plan literally would have declared 08-12 uncovered and diverted
the run to the unnecessary 08-13 fallback, whose 09:36 DOL touch makes the post-DOL stretch less
interesting. Measured: 6000/6000 bars in-window.
**Justified:** Yes.

### Divergence #2: `CallOutcome` has none of the field names the plan assumed

**Classification:** ✅ GOOD (plan gap corrected) / ⚠️ partially unmeetable
**Planned:** `_meta_from_outcome` reads `latency_sec`, `usage` and `cost` off `CallOutcome`.
**Actual:** The real dataclass carries `latency_total` and `usage_total`, and **no cost field at all**.
A `_META_ALIASES` table maps the meta names onto the real ones, and a divergence-guard test pins the
real shape.
**Reason:** The plan's names do not exist, so `_meta_from_outcome` would have recorded only `retries`
and `verdict` — making gate 8 vacuous on the real path while appearing to pass.
**Root Cause:** Plan gap (names not verified against the tree).
**Impact:** Latency and tokens are now captured on both paths and proven by the seeded recording.
**Cost is NOT captured:** no price table exists anywhere in the tree, and the plan's claim that the
manual harness captures cost is false — it records `latency_total_sec` and `usage_total` only.
Gate 8 is met for latency and tokens and is **unmeetable as written for cost**.
**Justified:** Yes.

### Divergence #3: Gates 3 and 5 were unfalsifiable as specified

**Classification:** ✅ GOOD (gate hardened)
**Planned:** A `NetworkCallRefused` raised on a cache miss fails the replay.
**Actual:** `CachedThesisBackend` counts refusals; `run_replay` raises **after** the run based on the
counter; gate 5 asserts `calls == 0` **and** `hits >= 1`.
**Reason:** `Analyzer._call` and `TraderGraft.on_bar` both swallow every exception, so a raise inside
the bar loop reaches nobody — the replay would finish silently as a dark day and the gate would pass.
**Root Cause:** Framework behaviour (blanket `except Exception` on two layers of the bar path).
**Impact:** Positive — gates 3 and 5 can now actually fail. The `hits >= 1` half also prevents a
dark day from satisfying "zero calls" trivially.
**Justified:** Yes.

### Divergence #4: `facts["boundary"]` does not exist

**Classification:** ✅ GOOD (plan gap corrected)
**Planned:** The cache key and record take the boundary from `facts["boundary"]`.
**Actual:** A `boundary_hint` constructor argument was added; facts still win when they carry one.
**Reason:** `assemble_facts` returns exactly `DECIDE_THESIS_KEYS`, which has no `boundary`. Every real
recording keyed on `""` and stored `boundary: null` — collapsing the per-date separation the design
depends on.
**Root Cause:** Plan gap.
**Impact:** Positive; a test pins that two dates with identical facts do not collide.
**Justified:** Yes.

### Divergence #5: A failsafe verdict is no longer cached

**Classification:** ✅ GOOD (plan gap corrected — caught in production, not review)
**Planned:** `isinstance(thesis, dict)` guards against recording a failed call.
**Actual:** The cache also refuses to record `verdict == "failsafe"`.
**Reason:** `decide_thesis` never returns `None` on failure — past `MAX_RETRIES` it substitutes a
synthetic NEUTRAL block with `verdict="failsafe"`. That is a dict, so the plan's guard never fires on
the real path.
**Root Cause:** Plan gap (an assumed failure shape that the real function does not produce).
**Impact:** Caught the hard way: the **first** seeding run cached exactly such a failsafe
(`retries: 2`, bias NEUTRAL) as a permanent dark day for 2026-08-12. The cache was cleared and
re-seeded after the fix; the final recording is `retries: 0, verdict: clean`.
**Justified:** Yes.

### Divergence #6: `replay_slice` duplicated the history's final 1m bar (HIGH)

**Classification:** ✅ GOOD (defect found in code review and fixed)
**Planned:** Select bridge bars from the 1s tape with `index > hist_end`, resample, concatenate.
**Actual:** The bridge is filtered **by bin label after resampling**.
**Reason:** `hist_end` is a bin LABEL, not the bin's end. Selecting `> hist_end` readmitted the 59
seconds belonging to a minute the history already carries; the resample re-stamped them onto the same
label, producing a duplicate row with a truncated Open and Volume and a **non-unique DatetimeIndex**
on the frame handed to `SessionPipeline` — double-counted in level/FVG detection, and every
`InvalidIndexError` it would cause is swallowed by `TraderGraft.on_bar`.
**Root Cause:** Plan gap plus a test fixture that could not expose it — the plan built `hist_1m` from
a separate `date_range`, so the 1s frame contained no bars inside the history's final minute. Real
geometry (both frames from one continuous tape) always does.
**Impact:** High-severity silent data corruption in exactly the frame the whole hist-extension
finding exists to protect. Three regression tests using the real parquet's shape were added.
**Justified:** Yes.

## Challenges & Resolutions

**Challenge 1: The first seeding run permanently cached a dark day**

- **Issue:** The 2026-08-12 recording came back NEUTRAL with `retries: 2`.
- **Root Cause:** `decide_thesis` substitutes a synthetic NEUTRAL block with `verdict="failsafe"`
  instead of returning `None`, so the plan's `isinstance(thesis, dict)` guard admitted a failed call
  into a content-addressed store — where it would have been served forever.
- **Resolution:** Refuse to record `verdict == "failsafe"`; clear the cache; re-seed
  (`retries: 0, verdict: clean`).
- **Prevention:** Never guard a cache write on an assumed failure sentinel — assert on the *success*
  marker the producer actually emits.

**Challenge 2: Three separate gates were incapable of failing**

- **Issue:** Gates 3, 5 and 6 all passed on code paths that could not have detected the condition
  they claim to assert (swallowed exceptions; a file written before the event under test).
- **Root Cause:** The plan specified assertions without checking whether the surrounding machinery
  could propagate a failure into them.
- **Resolution:** Counter-based refusal detection surfaced after the run; `last_bar_minute()` for
  continuation; `hits >= 1` alongside `calls == 0`.
- **Prevention:** For every gate, deliberately break the property and confirm the test goes red
  before accepting it as green.

**Challenge 3: The duplicated 1m bridge bar**

- **Issue:** A non-unique `DatetimeIndex` on the frame feeding the Analyzer and Executor, with a
  truncated Open/Volume on the duplicate.
- **Root Cause:** Treating a resample bin label as a bin end, in code whose own test fixture was built
  from geometry that cannot express the bug.
- **Resolution:** Filter the bridge by label after resampling; three regression tests built from the
  real parquet's shape.
- **Prevention:** Fixtures for frame-splicing code must be derived from one continuous tape, the way
  production frames are.

## Known Gaps and What Remains Unverified

1. **Cost is not captured.** No price table exists anywhere in the tree, and `CallOutcome` carries no
   cost field. Gate 8's cost clause cannot be met without introducing per-model pricing.
2. **`schema_fn` in `replay.py` returns `{}`,** so the JSON schema — which the plan lists as a keyed
   input — is inert in the key. *Mitigated:* the schema is derived from `facts`, and `facts` IS keyed
   via `facts_text`, so a schema change cannot occur without a facts change. Rebuilding the schema
   here would duplicate `decide_thesis`'s derivation in a second place — precisely the drift the
   content-addressed design exists to prevent.
3. **The recorded thesis is a single sample from a non-deterministic call.** This is the plan's own
   "single-sample confound" deferral: after an Analyzer change, an observed Executor difference
   conflates "the prompt changed" with "the model resampled". Attributing an effect needs N samples
   per key or an explicit acceptance of the confound.
4. **Only one date (2026-08-12) is validated**, by the plan's decision. The remaining §11 named cases
   (07-31, 08-05, 08-07, 08-14, 08-18) have no recorded theses.
5. **One gate assertion is skipped, not proven, on live data:**
   `test_gate6_a_dol_touch_is_recorded_with_its_timestamp` — the recorded thesis's DOL sits above the
   window high. The forced-DOL tests prove the same property deterministically.
6. **Open code-review findings, deliberately not addressed** (full detail in
   `.agents/code-reviews/22.replay-trading-session-cycle2.md`):
   - *MEDIUM* — a date with no window data completes "successfully": `run_backtest_v2` skips the date
     before the trader factory fires, so `run_dir` is `None`, every cache counter is 0, the refusal
     check passes, and the CLI prints `done -> None`. Applies to weekends, holidays and dates without
     1s coverage. The `hits >= 1` guard that would catch it lives only in the gate module, not the
     runner.
   - *LOW* — `_prompt_parts` reads `_TASK_THESIS` and `DEFAULT_MODELS` with `getattr` fallbacks, so a
     rename would silently drop a keyed input from the hash. `test_gate4_the_real_kb_bytes_are_what_
     the_key_hashes` surfaces it in the suite, but the runtime path degrades silently.
   - *LOW* — `build_replay_trader` constructs an Analyzer and immediately overwrites `graft._analyzer`,
     reaching into a private attribute and reading `thesis_state.json` twice per date.
7. **Deferrals carried forward from the plan:** attempt accounting for a plan that reaches 11:00 with
   attempts unspent (undefined; becomes real when cycle 3 lands the counter — *the operator asked to

## Recommendations for Future

**Plan improvements**

- **Verify every named symbol and field against the tree before writing the assertion that reads it.**
  Four divergences (#1, #2, #4, #5) are the same failure: a plausible-looking attribute that does not
  exist, or exists under a different name, wrapped in code that degrades silently rather than failing.
- **For each gate, state how it fails.** Three gates (#3, #8) were green against machinery that could
  not have propagated a failure. A gate whose failure mode is unstated is a gate that does not exist.
- **Measure the baseline at plan time, not from memory.** The plan predicted `2 failed, 1391 passed`;
  the real baseline at `0121632` was `4 failed, 1389 passed`.
- **Do not let a constraints section contradict the verified-facts table** (#9). The "legacy engine
  does not run in replay" line and the "the hook is additive and does not early-return" row cannot
  both be true.

**Process improvements**

- **Fixtures for frame-splicing code must share production geometry.** A fixture built from a separate
  `date_range` hid a HIGH-severity index corruption behind a passing test (#6).
- **Treat blanket `except Exception` layers as gate-defeating infrastructure.** Any assertion that
  depends on an exception crossing `Analyzer._call` or `TraderGraft.on_bar` needs a counter or a
  post-run check instead.
- **Any env var a helper sets must be restored by the caller that owns the scope** (#11).

**CLAUDE.md candidates**

- "A cache write must be guarded on the producer's *success* marker, never on an assumed failure
  sentinel" — the failsafe-verdict class of bug (#5).
- "When resampling, a bin label is not a bin end: filter derived frames by label *after* resampling,
  and assert `index.is_unique` on any frame built by concatenation" (#6).
- "A source-text grep is not a test: use an AST walk that excludes docstrings, plus a behavioural
  assertion" (#10).
