# 41. Operator overrides: set direction, set/reset target (⚠️ Medium)

Two `trade.py` commands that steer the RUNNING agent without a restart, plus the plumbing
that makes them reproducible in a replay. Source: the 2026-09-21/22 sessions — the only
way to set direction was editing `thesis_state.json` and restarting, which cost 14 minutes
of arm time and changed which entries the day could take (session-analysis D1).

Worktree `operator-overrides`, branch `feat/operator-overrides`, off `live` @ 2da4d0b.

## Semantics (pinned by the operator, 2026-09-23)

- **set-direction** — before an entry or between failed attempts.
  - Refused while a position is open (close first).
  - Kills the current plan and derives a NEW plan in the requested direction.
  - **Remaining attempts CARRY OVER** (`attempts_used` is preserved). `--reset-attempts`
    restores a full budget explicitly.
  - The 10:30 entry cutoff and the 13:00 flatten still apply; the thesis on disk is NOT
    rewritten (it stays the model's record) — the override is its own record.
- **set-target** — during position management.
  - Refused before a fill, and refused unless a default target was selected at that fill.
  - Refused on the wrong side of the entry (that would be an immediate exit).
  - Picked from the CURRENT menu by row id (`D2`) or level name; a raw `--price` needs an
    explicit flag.
  - The initial target is re-derived from the new target (still `action="record"`).
  - The fill's default is stored, so `--reset` restores it.
- **Applied on a bar boundary, never mid-bar, never off a wall clock** (CLAUDE.md).
- **Recorded**: every override, accepted or rejected, is a `trader_decisions.jsonl` record
  carrying BAR time, so a replay can reproduce the session.

## Deliverables

- [ ] `agent/trader/operator_control.py` — append/read the `operator_control.jsonl`
      control file (one JSON record per command, monotonic `seq`). No `live_orders`,
      no clock inside the bar loop.
- [ ] `Executor`: remember the fill's default target; `set_target_override(now, price,
      level)`; `reset_target(now)`; `target_menu(now)` + write `target_menu.json`.
- [ ] `TraderGraft`: drain pending control records on each bar close, before
      `Executor.on_bar`; apply direction (kill + re-derive, attempts carried) and target;
      record accepted/rejected.
- [ ] `records.DecisionRecorder.operator_override(...)`.
- [ ] `trade.py`: `agent-direction up|down [--reset-attempts]`,
      `agent-target <D2|level|--price P> [--reset] [--list]`. Guards read
      `position.json` / the artifacts; the command never touches the broker.
- [ ] `scripts/replay_session.py --operator-control <file>` to reproduce a session.
