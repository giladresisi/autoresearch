# L1 Thesis Evidence Facts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the L1 thesis model (`agent-docs/strategy/decisions/thesis.md`) the facts it needs
for its four primary evidence criteria (P1 HTF close beyond/before at any sweep, P2 meaningful-SMT
+ HTF rejection, P3 daily/weekly equilibrium position, P4 HTF-confirmed mid reclaim) — none of
which are currently computed or exposed by `agent/derive_facts.py`.

**Architecture:** Extend `FactsBundle`/`compute_facts` with new structured fields computed
alongside the existing S0-S7 pass (weekly mid, per-level sweep timestamps, HTF close-status,
cross-ticker SMT candidates), then surface them to the model two ways: (a) new S8
predicate-menu families (`_MENU_PREDICATE_CFG`) covering both tickers, weekly mid, and swept
levels; (b) a new `render_evidence_text` block, additive and separate from the byte-stable S0-S7
core exactly like `render_menus_text` already is. `agent/bench/facts.py` wires the new render
function into the model-facing prompt.

**Tech Stack:** Python, pandas (bar resampling), pytest.

## Global Constraints

- **Byte-stability is non-negotiable.** `render_facts_text` (S0-S7) and `facts_to_validator_dict`
  are hashed for shadow-engine facts identity (`facts_adapter._canonical_hash`) and covered by a
  golden-fixture test (`agent/test_derive_facts_lib.py::test_render_facts_text_byte_identical_to_golden`).
  Every new field in this plan is computed as a plain `FactsBundle` dataclass field and NEVER
  appended to `bundle.lines` — follow the exact precedent of `day_mid` ("not rendered in S1") and
  the S8 `menus` field. No task in this plan may add a new `L(...)` call to the existing S0-S7
  sections.
- **No lookahead.** All new computation must only use `data[tkr]` (already truncated to `<= now`
  inside `compute_facts`) — never the untruncated `hist_mnq`/`hist_mes` frames for anything
  time-sensitive.
- **1h/4h timeframes need no executor changes.** `agent/contracts/predicates.py` already declares
  `TIMEFRAMES = {"1m","5m","15m","1h","4h"}` and both `agent/executor/primary_runner.py`'s
  `_closes_by_tf` and `agent/bench/lifecycle.py`'s `_closes_by_tf` already resample generically
  over all declared timeframes. This plan is confined to the facts/menu layer
  (`agent/derive_facts.py` + its tests + `agent/bench/facts.py`'s wiring) — do not touch
  `agent/contracts/predicates.py`, `agent/executor/*`, or `agent/bench/lifecycle.py`.
- **No validator changes needed.** `agent/contracts/validate_contracts.py`'s `classify_predicates`/
  `_menu_index` iterate `facts["menus"]["predicates"][direction]` generically (no hardcoded
  family list), and `validate_thesis` accepts any schema-valid, facts-grounded predicate via the
  documented escape hatch (`agent/contracts/test_menu_membership.py`). New menu families and new
  escape-hatch predicates referencing existing facts-sheet level names validate with zero changes
  to `agent/validator.py` or `agent/contracts/validate_contracts.py`. Confirmed by inspection —
  do not add a "validator updates" task.
- **Terminology: do not reuse the existing S3 "lead" text.** The S3 cross-ticker matrix's
  `"<-- WICK DIVERGENCE CANDIDATE (lead X)"` text means "X is the ticker that swept" — the
  OPPOSITE of `thesis.md`'s "leader" (the asset that FAILED to confirm). Do not rename or touch
  that existing rendered text (byte-stability). The new structured field in this plan uses
  neutral names `swept_ticker` / `unswept_ticker` instead; `thesis.md`'s prose maps
  `unswept_ticker -> "leader"`, `swept_ticker -> "lagger"`.
- **All existing tests must keep passing unmodified:** `agent/test_derive_facts_lib.py`,
  `agent/test_menus.py`, `agent/contracts/test_menu_membership.py`,
  `agent/contracts/test_predicates.py`, `agent/bench/test_facts.py`. New optional
  parameters/fields must default such that old call sites/fixtures (which don't set them) produce
  the exact same output as today.
- Run the full existing suite before starting (`pytest agent/ -q` from the repo root, or scope to
  `agent/test_derive_facts_lib.py agent/test_menus.py agent/contracts/test_menu_membership.py
  agent/contracts/test_predicates.py agent/bench/test_facts.py`) and record the baseline pass
  count — Task 7's final step re-runs this same command and must show the same baseline plus the
  new tests, nothing newly broken.

```python
def _beyond_side(value: float, price: float, side: str) -> bool:
    return value > price if side == "above" else value < price


def _htf_close_status(df: pd.DataFrame, swept_at: Optional[pd.Timestamp], *,
                       price: float, side: str, now: pd.Timestamp) -> dict:
    """For a level swept at `swept_at`, classify the most recent COMPLETED 1h/4h bar
    (midnight-anchored, engine convention) that CLOSED strictly after the sweep and at/
    before `now`. Returns {"1h": None, "4h": None} when `swept_at` is None (never swept)
    or when no qualifying bar has closed yet since the sweep — the maturity gate
    (decisions/thesis.md §3): an immature sweep is not usable evidence in either
    direction. Otherwise {tf: {"close": float, "beyond": bool, "closed_at": Timestamp,
    "n_closed_since": int}} — `beyond` reflects the MOST RECENT qualifying close (a
    running/current-state read, matching the RUNNING-mid convention used elsewhere in
    this module), `n_closed_since` is how many qualifying bars exist (>=1 by
    construction when not None)."""
    out: dict = {}
    if swept_at is None:
        return {"1h": None, "4h": None}
    for tf, freq in (("1h", pd.Timedelta(hours=1)), ("4h", pd.Timedelta(hours=4))):
        bars = ohlc(df, tf).iloc[:-1]              # drop the still-forming trailing bar
        if len(bars) == 0:
            out[tf] = None
            continue
        closed_at = bars.index + freq              # left-labeled bin -> actual close time
        mask = (closed_at > swept_at) & (closed_at <= now)
        eligible = bars[mask]
        if len(eligible) == 0:
            out[tf] = None
            continue
        close = float(eligible.iloc[-1]["close"])
        out[tf] = {
            "close": close,
            "beyond": _beyond_side(close, price, side),
            "closed_at": (eligible.index + freq)[-1],
            "n_closed_since": int(len(eligible)),
        }
    return out
```

```python
def _resolve_level_class(level_class: str, direction: str, mnq_levels: dict,
                         vlevels: dict, now_price: float, day_mid, dol_menu: dict,
                         max_levels, *, weekly_mid=None, mes_levels=None,
                         mnq_swept_at=None, mes_swept_at=None,
                         smt_candidates=None) -> list:
    """Resolve a level-class to a list of (price, side) the builder fills into predicates."""
    if level_class == "daily_mid":
        if not isinstance(day_mid, (int, float)):
            return []
        return [(day_mid, _anti_side(direction))]
    if level_class == "weekly_mid":
        if not isinstance(weekly_mid, (int, float)):
            return []
        return [(weekly_mid, _anti_side(direction))]
    if level_class == "clock":
        return [(None, None)]
    if level_class == "dol_pools":
        side = _thesis_side(direction)
        return [(e["price"], side) for e in dol_menu.get(direction, [])]
    if level_class == "anti_pools":
        side = _anti_side(direction)
        pools = []
        for name, tup in mnq_levels.items():
            price, _body, lside, _tier, _active = tup
            if lside not in ("above", "below") or not isinstance(price, (int, float)):
                continue
            v = vlevels.get(name, {})
            if v.get("swept") or v.get("depleted"):
                continue
            if direction == "UP" and lside == "below" and price < now_price - _EPS:
                pools.append(price)
            elif direction == "DOWN" and lside == "above" and price > now_price + _EPS:
                pools.append(price)
        pools.sort(key=lambda p: abs(p - now_price))
        if max_levels:
            pools = pools[:max_levels]
        return [(p, side) for p in pools]
    if level_class == "swept_levels":
        # thesis.md P1: any swept, in-facts level on EITHER ticker whose maturity gate
        # (>=1 qualifying HTF close since the sweep) has passed — enforced here by
        # requiring a swept_at entry, not merely a bundle.levels entry. Direction-neutral:
        # both UP and DOWN offer the same swept-level pools (P1 scores whichever side the
        # model's read matches; the level's own `side` decides "beyond" vs "before").
        out = []
        for levels_, swept_map in ((mnq_levels, mnq_swept_at or {}),
                                   (mes_levels or {}, mes_swept_at or {})):
            for name, tup in levels_.items():
                price, _body, lside, _tier, _active = tup
                if lside not in ("above", "below") or not isinstance(price, (int, float)):
                    continue
                if swept_map.get(name) is None:
                    continue
                out.append((price, lside))
        return out
    if level_class == "meaningful_smt_pools":
        # thesis.md P2: week/day-tier SMT candidates only, tested on the SWEPT ticker's
        # own price at the ANTI-side (a close BEFORE the liquidity on the unswept/
        # leader's side is what P2 scores as a reversal tell).
        out = []
        levels_by_tkr = {"MNQ": mnq_levels, "MES": mes_levels or {}}
        for cand in smt_candidates or []:
            if not cand.get("meaningful"):
                continue
            tup = levels_by_tkr.get(cand["swept_ticker"], {}).get(cand["level"])
            if tup is None:
                continue
            price = tup[0]
            anti_side = "below" if cand["side"] == "above" else "above"
            out.append((price, anti_side))
        return out
    return []
```

```python
def render_evidence_text(bundle: FactsBundle) -> str:
    """Render the S9 thesis-evidence block (decisions/thesis.md P1/P3/P4 inputs): weekly
    mid, per-level HTF close-status on BOTH tickers, and SMT candidates with tier
    eligibility. Kept SEPARATE from render_facts_text (S0-S7 stays byte-identical) and
    from render_menus_text (S8) — additive, never hashed, never in bundle.lines."""
    out: list = []
    A = out.append
    A("## S9 THESIS EVIDENCE (decisions/thesis.md P1-P4 inputs)")
    A(f"weekly_mid = {bundle.weekly_mid}")
    A("\nHTF close-status per swept level (maturity gate: 'immature' = no qualifying HTF "
      "close yet since the sweep -> NOT usable evidence, decisions/thesis.md §3):")
    for tkr in ("MNQ", "MES"):
        status = (bundle.htf_close_status or {}).get(tkr, {})
        if not status:
            A(f"  {tkr}: (none)")
            continue
        for name, tf_map in status.items():
            for tf in ("1h", "4h"):
                info = (tf_map or {}).get(tf)
                if info is None:
                    A(f"  {tkr} {name} [{tf}]: immature (no qualifying close yet)")
                else:
                    read = "ACCEPTED beyond" if info["beyond"] else "REJECTED (closed before)"
                    A(f"  {tkr} {name} [{tf}]: close={info['close']} @ {info['closed_at']} "
                      f"(n={info['n_closed_since']}) -> {read}")
    A("\nSMT candidates (meaningful = day/week tier, eligible for thesis.md P2; "
      "swept_ticker = confirmed/pushed through (lagger); unswept_ticker = failed to "
      "confirm (leader)):")
    if not bundle.smt_candidates:
        A("  (none)")
    for cand in bundle.smt_candidates:
        A(f"  {cand['level']} [{cand['side']}, {cand['tier']}]: "
          f"swept_ticker={cand['swept_ticker']} (lagger) "
          f"unswept_ticker={cand['unswept_ticker']} (leader) "
          f"type={cand['type']} swept_at={cand['swept_at']} "
          f"meaningful={cand['meaningful']}")
    return "\n".join(out) + "\n"
```
